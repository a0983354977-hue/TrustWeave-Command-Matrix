    ABOUT THIS BUILD

    TrustWeave Command Matrix

    Every drop is routed straight into the Rust engine over Tauri IPC. Nothing leaves this machine and no verdict is ever simulated.

    Mode 01 — Internal Defense: builds a deterministic SHA-256/BLAKE3 ledger, renders the Merkle-DAG, and mints a credential. Projects carrying tw-policy.json, a Lean proof, and a built executable are signed into a full .twledger with Ed25519; otherwise a self-contained ledger credential is written and the Merkle root is copied.

    Mode 02 — Threat Hunting: sweeps a file or folder through the pure-Rust YARA-X engine, sweeping a live radar and pinning every matched file with its rule and description.
